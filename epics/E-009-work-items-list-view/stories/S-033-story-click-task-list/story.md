# S-033: Story click shows task and bug list

## User story

As a user, when I click a story in Work items I want to see that story’s tasks and bugs so I can drill into delivery work.

## Acceptance criteria

- [ ] Clicking a **story** row shows the task/bug list for that story (same behavior as Overall story selection where practical).
- [ ] Clicking a task/bug opens the existing detail sheet (or agreed default) without requiring story drill-down.
- [ ] User can return to the Work items list after drilling into a story.

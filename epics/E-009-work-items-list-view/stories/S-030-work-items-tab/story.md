# S-030: Work items tab in board switcher

## User story

As a user, I want a Work items tab on the board so I can open a dedicated list of stories, tasks, and bugs.

## Acceptance criteria

- [ ] Board view switcher includes a **Work items** tab (label may be Work items / Workitems; id `workitems`).
- [ ] Selecting the tab activates the Work items view mode without breaking Overall or other existing modes.
- [ ] Default view remains Overall unless otherwise changed later.

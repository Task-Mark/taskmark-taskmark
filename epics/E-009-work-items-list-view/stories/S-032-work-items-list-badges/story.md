# S-032: Work items list with epic and priority badges

## User story

As a user, I want each Work items row to show epic and priority badges so I can see parent epic and urgency at a glance.

## Acceptance criteria

- [ ] Each row shows an epic badge with the epic **code** only (e.g. `E-009`).
- [ ] Hovering the epic badge shows a tooltip with the epic **title**.
- [ ] Each row shows a priority badge.
- [ ] Row type (story / task / bug) is visually distinguishable.

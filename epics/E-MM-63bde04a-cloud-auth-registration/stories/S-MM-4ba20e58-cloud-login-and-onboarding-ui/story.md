# S-MM-4ba20e58: Cloud login and onboarding UI

## User story

As a visitor to Taskmark Cloud, I want login, a registration wizard, email verification, and invite acceptance screens that match the existing interface, so I can complete onboarding without leaving the product look.

## Acceptance criteria

- [ ] Public routes cover login, register, verify-email, and invite acceptance.
- [ ] Registration walks Account, Project, Invites, then Verify email.
- [ ] The browser talks only to same-origin API proxy routes that forward cookies.

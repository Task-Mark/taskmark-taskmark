# S-MM-0262f947: Conventions, docs, and plugin sync

## User story

As a contributor, I want conventions, the always-apply rule, READMEs, and public docs to name `/tkmd-changelog` and `/tkmd-version` and to allow `CHANGELOG.md` (not a generated README changelog).

## Acceptance criteria

- [ ] Conventions and project-memory list the new commands and forbid README changelogs while allowing board `CHANGELOG.md`
- [ ] Plugin README, board README, and website command docs describe both commands
- [ ] Local plugin install is synced after the plugin package changes
